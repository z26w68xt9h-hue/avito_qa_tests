# Тестирование API микросервиса Avito

## Описание проекта
Данный проект содержит полную документацию по тестированию API микросервиса Avito для сервиса объявлений. API представлен в двух версиях: v1 и v2.

## Содержимое проекта
- **TESTCASES.md** — подробное описание тест-кейсов (64 теста)
- **BUGS.md** — отчет о выявленных дефектах (12 дефектов)
- **README.md** — описание проекта и инструкции по тестированию
