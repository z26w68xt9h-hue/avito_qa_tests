## Тестируемый API

### Базовый URL
https://qa-internship.avito.com

### Доступные версии API

#### API v1 (Основная версия)
| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| POST | `/api/1/item` | Создание объявления |
| GET | `/api/1/item/{id}` | Получение объявления по ID |
| GET | `/api/1/{sellerId}/item` | Получение всех объявлений продавца |
| GET | `/api/1/statistic/{id}` | Получение статистики (возвращает объект) |

#### API v2 (Расширенная версия)
| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| DELETE | `/api/2/item/{id}` | Удаление объявления по ID |
| GET | `/api/2/statistic/{id}` | Получение статистики (возвращает массив) |
