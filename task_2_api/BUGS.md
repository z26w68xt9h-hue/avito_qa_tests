## Детальное описание дефектов

### BUG-001: Корневой путь возвращает 400
**Шаги**: GET https://qa-internship.avito.com/
**Фактически**: 400 Bad Request, {"message": "route / not found", "code": 400}
**Ожидаемо**: Страница документации или редирект на /api/1

### BUG-002: Нет защиты от дублирования
**Шаги**: Создать два одинаковых объявления для одного sellerId
**Фактически**: Оба созданы успешно
**Ожидаемо**: 409 Conflict

### BUG-003: Статистика просмотров не обновляется
**Шаги**: Создать объявление, получить его 10 раз, проверить статистику
**Фактически**: viewCount = 0
**Ожидаемо**: viewCount = 10

### BUG-004: Отсутствуют CORS заголовки
**Шаги**: OPTIONS запрос к любому endpoint
**Фактически**: Нет CORS заголовков
**Ожидаемо**: Access-Control-Allow-* заголовки

### BUG-005: Пустое тело вызывает 500
**Шаги**: POST /api/1/item с {}
**Фактически**: 500 Internal Server Error
**Ожидаемо**: 400 Bad Request

### BUG-006: Отсутствует rate limiting
**Шаги**: 1000 запросов подряд
**Фактически**: Все успешны
**Ожидаемо**: 429 Too Many Requests после превышения лимита

### BUG-007: Неоднородная структура ответов
**Описание**: Разные endpoints возвращают данные в разных форматах (объект vs массив)
**Ожидаемо**: Унифицированный формат

### BUG-008: Нет валидации контактных данных
**Описание**: Можно создать объявление с некорректным email/телефоном
**Ожидаемо**: Валидация форматов

### BUG-009: Price пропускает спецсимволы
**Шаги**: POST с "price": "1000$"
**Фактически**: 200 OK
**Ожидаемо**: 400 Bad Request, price должен быть числом

### BUG-010: Некорректная обработка больших чисел
**Шаги**: price = 1000000 (создается), price = 9999999 (ошибка)
**Ожидаемо**: Единообразная валидация

### BUG-011: Разный формат статистики v1 и v2
**Фактически**: v1 возвращает объект, v2 возвращает массив
**Ожидаемо**: Единый формат

### BUG-012: DELETE возвращает неинформативный ответ
**Фактически**: {"result": "success", "status": "ok"}
**Ожидаемо**: {"success": true, "message": "Item deleted", "id": "..."}
