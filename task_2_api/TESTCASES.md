# Задание 2.1: Тесты API

## Базовый URL
`https://qa-internship.avito.com`

## Эндпоинты (из Postman-коллекции, версия 1)
| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| POST | `/api/1/item` | Создать объявление |
| GET | `/api/1/item/{id}` | Получить объявление по ID |
| GET | `/api/1/{sellerId}/item` | Получить все объявления продавца |
| GET | `/api/1/statistic/{id}` | Получить статистику |

---

## Позитивные сценарии

| ID | Название | Шаги | Ожидаемый результат |
|----|----------|------|---------------------|
| POS-01 | Создание объявления | POST `/api/1/item` с валидными name, price, sellerId | 200, получен id |
| POS-02 | Получение по ID | Создать объявление → GET `/api/1/item/{id}` | 200, данные совпадают |
| POS-03 | Список по sellerId | Создать 2 объявления → GET `/api/1/{sellerId}/item` | 200, оба в списке |
| POS-04 | Получение статистики | Создать объявление → GET `/api/1/statistic/{id}` | 200, структура JSON |

---

## Негативные сценарии

| ID | Название | Шаги | Ожидаемый результат |
|----|----------|------|---------------------|
| NEG-01 | Пустое name | POST с `name = ""` | 400 |
| NEG-02 | Только пробелы в name | POST с `name = "   "` | 400 |
| NEG-03 | Отрицательная цена | POST с `price = -100` | 400 |
| NEG-04 | Цена = 0 | POST с `price = 0` | 400 |
| NEG-05 | sellerId < 111111 | POST с `sellerId = 100` | 400 |
| NEG-06 | sellerId > 999999 | POST с `sellerId = 1000000` | 400 |
| NEG-07 | Отсутствует поле name | POST без поля name | 400 |
| NEG-08 | Отсутствует поле price | POST без поля price | 400 |
| NEG-09 | Отсутствует поле sellerId | POST без поля sellerId | 400 |
| NEG-10 | Несуществующий ID | GET `/api/1/item/invalid` | 404 |
| NEG-11 | Несуществующий sellerId | GET `/api/1/1/item` | 404 |
| NEG-12 | Статистика по несуществующему ID | GET `/api/1/statistic/invalid` | 404 |

---

## Корнер-кейсы

| ID | Название | Шаги | Ожидаемый результат |
|----|----------|------|---------------------|
| COR-01 | Идемпотентность создания | Два одинаковых POST запроса | Оба 200, id разные |
| COR-02 | Спецсимволы в name | POST с `name = "!@#$%^&*()"` | 200 |
| COR-03 | Очень длинный name | POST с name из 1000 символов | 400 или 200 |
| COR-04 | Статистика для нового объявления | Создать → сразу запросить статистику | 200, структура верна |
| COR-05 | Список для sellerId без объявлений | GET `/api/1/888888/item` | 200 (пустой список) или 404 |

---

## Нефункциональные проверки

| ID | Название | Шаги | Ожидаемый результат |
|----|----------|------|---------------------|
| NF-01 | Время ответа POST | Замерить время | < 2 сек |
| NF-02 | Время ответа GET | Замерить время | < 1 сек |
| NF-03 | Уникальность ID | Создать 10 объявлений, собрать id | Все id уникальны |
| NF-04 | Content-Type | Проверить заголовок ответа | application/json |

---

## Использованные техники тест-дизайна

| Техника | Где применена |
|---------|---------------|
| Классы эквивалентности | Валидные/невалидные значения полей |
| Граничные значения | price = 1, price = 999999999, sellerId = 111111, 999999 |
| Предугадывание ошибок | Пустые поля, отсутствие полей, пробелы |
| Идемпотентность | Повторные одинаковые запросы |
